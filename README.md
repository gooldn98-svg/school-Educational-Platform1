# منصة المدرسة التعليمية

منصة تعليمية عربية شاملة لإدارة العملية التعليمية بجميع جوانبها

## الميزات الرئيسية

### 👨‍💼 الإدارة
- إدارة الطلاب والمعلمين وأولياء الأمور
- إدارة الصفوف والفصول الدراسية
- إدارة المواد والمناهج
- الإحصائيات والتقارير

### 👨‍🏫 المعلمون
- إنشاء الدروس والمحاضرات
- تعيين الواجبات والمشاريع
- إنشاء الاختبارات والامتحانات
- تقييم الطلاب
- متابعة التقدم الأكاديمي

### 👨‍🎓 الطلاب
- الوصول إلى المواد الدراسية
- حل الواجبات والاختبارات
- متابعة درجاتهم
- التواصل مع المعلمين
- تحميل الموارد التعليمية

### 👨‍👩‍👧 أولياء الأمور
- متابعة تقدم أطفالهم
- عرض الدرجات والتقارير
- تلقي التنبيهات عن الغياب والأداء
- التواصل مع المدرسة

## المناهج المدعومة
- المنهج اليمني (الصفوف 1-12)
- العربية والرياضيات والعلوم والإنجليزية والدراسات الاجتماعية وغيرها

## التكنولوجيا المستخدمة
- HTML5 و CSS3 و JavaScript
- Node.js و Express.js
- MongoDB
- Bootstrap للواجهة المتجاوبة

## الصفوف الدراسية المدعومة
- المرحلة الابتدائية: 1-6
- المرحلة الإعدادية: 7-9
- المرحلة الثانوية: 10-12
